Chakra-fin

Chakra-fin is a personal finance tool that tracks your expenses automatically. It reads bank transaction alert emails (for example, "debited" notifications) from your Gmail account, pulls out the amount, merchant and date, and sorts each transaction into an expense category.

How it uses Google data

  • It asks for read-only Gmail access (https://www.googleapis.com/auth/gmail.readonly).
  • It only searches for transaction alert emails. It never sends, deletes or changes your email.
  • The transaction details it extracts are stored only to show you your expense history.
